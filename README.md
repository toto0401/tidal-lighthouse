# 潮汐灯塔

用 Godot 4.7 制作的 3D 海岛小游戏：在柔和的海风里收集九件遗物，依次点亮灯塔、恢复风铃花园、唤醒星砂海湾，再和回家的小海豹一起散步。没有战斗、倒计时或失败惩罚。

## 开始玩

Mac 上双击 `release/潮汐灯塔.app`，再点「开始旅程」或「继续旅程」。独立应用无需安装 Godot。`开始游戏.command` 运行同目录中的 Godot 工程，适合修改后试玩。已有旧版进度会自动兼容。

当前标准版为 1.4.0，包含小动物和此前的配乐、闲趣、游泳与冲刺。带「配乐版」「互动版」「新主角」后缀的应用为保留的旧快照；体验本次更新请打开标准版。

带昼夜背景音乐的独立应用为 `release/潮汐灯塔-配乐版.app`，可直接打开，沿用现有进度和声音设置。

游戏画面只保留当前目标、基础操作和状态；完整遗物线索按 J 或点击右下角「潮汐手账」查看。帮助和其他菜单会按窗口大小调整，内容较长时可以滚动，右上角关闭按钮始终保留。

小屋已经搬进灯塔：靠近主岛塔门按 E，进入独立的小屋场景；走到右后方楼梯按 E，再切换到塔顶。灯芯修复点位于塔顶灯室前，收集漂流木星标、月光海玻璃和回声贝壳后可修复。小屋和塔顶从开局即可进入，不必先收集遗物。塔顶楼梯可回小屋，小屋门可回海岛；Tab 地图中的「回到灯塔」会直接返回室外。家具和档案台都在小屋里，原有配色、布局与修复进度保留。

塔顶右侧有带风向袋的起飞点：靠近按 E，展开海盐绿与奶油色的滑翔翼，飞回真实海岛。室外从其他高处跳下或落下，离地至少 2 米时按 G 也可展开。WASD 按镜头方向转向，松开方向键会继续前进并缓慢下降；G 或空格收翼，足够高时可再次按 G 展开。滑翔无法增加高度，落地或入水自动收起，入水后可以继续游泳；碰到墙壁会结束滑翔，抵达近海边界会转向岛屿。无需解锁或消耗物品。菜单暂停空中移动，关闭后继续，失焦自动暂停；Tab 可随时回家。

先去灯塔东南边找漂流木星标。手账会写出接下来物品的位置、潮汐和时间；旋转镜头后按 C 可回正，画面上方是北。集齐一组物品后，左侧提示会指向对应修复点。风铃种子在东侧绣球花岛，银白羽毛在西侧月贝沙洲；最后一件星砂小瓶需要恢复花园后，在月夜退潮时去北方观星岬找。按 Tab 查看地图，地图中的「回到灯塔」可帮助返程。

踏浪冲刺从开始就能使用：脚下唤出一道蓝色浪花，约 0.65 秒滑行 8 米，结束后冷却 1.5 秒。左下角显示就绪和蓄能进度。陆地和游泳时都能发动；空格中断冲刺，陆地上会同时起跳，菜单和回家也会结束冲刺。沿岛屿和木桥滑行，遇到实体墙壁会停住；越过海岸或桥边会转为游泳并继续剩余冲刺，游向岸边会自动上岸。长按 Shift 不会自动连发。

海岸和桥边不再有强制拉回角色的空气墙。走入水中后自动浮起，WASD 按镜头方向游泳，Shift 可在水面冲刺，靠近低矮岸边和木桥会自动上岸；没有体力消耗和溺水惩罚。可以游过岛屿之间的水域，活动范围限制在距离最近岛岸约 12 米的近海。靠近外缘会出现「前方是远海」提示，继续向外游或冲刺会停在边界，仍可沿边缘游动或转向返回。按 Tab 使用「回到灯塔」返程。

岸边或木桥边站稳后会出现「F 岸边钓鱼」。按 F 抛竿，等浮漂晃动、响起提示音并显示「鱼儿咬钩了」，再按 F 收竿。咬钩提示会一直保留，不必抢时间。提前按 F、走动、跳跃、冲刺或打开菜单会收起鱼竿。银鳞小鱼全天可遇，晴海青鲭在白昼出现，月光灯鱼在月夜出现，珊瑚海鲷随涨潮到来；四种鱼和累计数量自动记入 J 手账。

## 岛上闲趣

新增互动版应用：`release/潮汐灯塔-互动版.app`，双击即可玩，沿用原来的存档与配乐。

四处闲趣从旅程开始就可以游玩。按 Tab 看地图上的绿色菱形，走近后按 E；收获在 J 手账上方的「岛上闲趣」查看，也可以从暂停菜单进入。

| 地点 | 玩法 |
| --- | --- |
| 主岛北岸木码头尽头 | 打水漂：E 准备，指针进入深绿区时再按 E 投出。瞄准中央挑战五跳，保存最佳纪录。 |
| 东侧绣球花岛，茶席西南 | 浇花：点击花盆或按 1 / 2 / 3，各浇三次，从种子长到盛开。岛上的三维花圃也会成长。 |
| 西侧月贝沙洲，贝壳雕塑东南 | 风铃：跟着数字谱点击或按 1 / 2 / 3，可先听示范、切换三首曲子。静音时可看风铃的亮光。 |
| 北方观星岬，亭内望远镜 | 连星：月夜依次点亮 1 → 5，收集两张星图；白天可选择「等到月夜」。 |

共有九项闲趣记录：五跳水漂、三盆花、三首旋律、两张星图。可随时 Esc 离开，没有物品消耗；新纪录和每次浇水都会自动保存，重新开始时一起备份。闲趣与原来的九件遗物独立。小窗口下显示紧凑布局，指示图与操作按钮可同时看见。

## 岛上的小动物

八位小邻居从开局就在岛上生活：三只兔子、两只螃蟹和三只海鸥。靠近出现 E 提示后，可以摸摸兔子或向螃蟹、海鸥打招呼；它们会短暂停下来回应，冒出爱心，随后恢复自己的活动。

| 地点 | 小动物 |
| --- | --- |
| 主岛 | 兔子「奶糖」、海鸥「小帆」 |
| 东侧绣球花岛 | 兔子「云朵」和「桃酥」 |
| 西侧月贝沙洲 | 螃蟹「桃桃」和「小夹子」、海鸥「海盐」 |
| 北侧观星岬 | 海鸥「阿白」 |

白天，它们会自己闲逛，停下时也会嗅闻、转头、动钳子或整理翅膀；站在旁边观察不会让它们一直停住。海鸥偶尔短程飞行，再飞回栖息地。夜里兔子和海鸥休息，螃蟹仍会活动。海湾恢复后的小海豹「雾团」仍会回家，在码头附近自行散步、休息，偶尔陪你走一段。动物不需要解锁或喂养，不改变已有存档。

## 自动存档与配乐

小岛会随游玩时间自动昼夜交替：白昼约 4 分钟、月夜约 3 分钟，每轮约 7 分钟。日落和天亮时，天空、海水、灯光和配乐在 20 秒内平滑过渡，夜间遗物、鱼类与动物作息随之变化。喝茶、钓鱼、游泳和在灯塔里休息时也会继续走时；标题、菜单和场景切换期间暂停。N 可随时切换，并从所选时段重新计时，不必等候。

白昼播放原创轻器乐《海风慢步》，月夜播放更安静的《月色潮汐》。两首配乐每首约 1 分 47 秒，无缝循环；按 N 切换昼夜时以 3 秒淡入淡出衔接。标题和暂停时也能继续听，音乐与海浪、提示音一起受 M 键控制，声音偏好自动保存。音频随游戏提供，无需联网。

钓鱼记录、发现、修复、潮汐、昼夜与当前时段进度、房间配色、三套家具陈列、四套雨衣颜色和声音设置自动保存。时钟每 30 秒存档，切换昼夜与正常退出时也会保存；再次打开从保存的时段接着走，关闭游戏期间不计时。旧存档保留原来的白昼或月夜；新旅程从白昼开始。再次打开从灯塔附近开始，已完成的进度保留。角色位置不保存。

暂停菜单里可以重新开始；确认后会先把原存档复制为 `progress.cfg.backup.*`，再创建新进度。备份失败时不重置。Mac 存档目录：

`~/Library/Application Support/Godot/app_userdata/潮汐灯塔/`

## 工程与内容

用 Godot 4.7 打开 `project.godot`，按 F5 运行。主场景为 `Main.tscn`；几何、碰撞、角色与交互位于 `main.gd`；九件物品数据位于 `data/island_catalog.gd`；菜单与岛屿生物位于 `scripts/`；游泳浮力和上岸在 `main.gd`，钓鱼状态与水面效果在 `scripts/water_activities.gd`，鱼类数据在 `data/fish_catalog.gd`。海面使用动态 shader，字体和音效随游戏提供。

灯塔小屋和塔顶分别为 `scenes/LighthouseRoom.tscn`、`scenes/LighthouseTop.tscn`，场景切换由 `scripts/lighthouse_travel.gd` 管理。角色、菜单、音乐和进度持续保留；进入小屋时海岛隐藏、暂停并关闭碰撞。登上塔顶时，露台位于真实灯塔上方，显示同一份海岛场景，木桥、花园、茶席、动物和昼夜潮汐保持同步。拖动或方向键转镜头，滚轮可拉远查看四岛全景，C 恢复塔顶视角。小屋和露台按需加载、离开时卸载。底座与露台均为半径 6.2 米，18 米高的观景台下是向上收窄的塔身，顶部设海绿色小尖顶灯室；外墙、门窗、入口和滑翔离塔位置共用 `data/lighthouse_layout.gd` 的尺寸。

滑翔状态、离地探测、方向控制与滑翔翼模型位于 `scripts/gliding.gd`；塔顶起飞经场景切换回到室外空中，仍使用原角色的实体碰撞和游泳逻辑。滑翔不新增存档字段。

这是有完整起点和结局的小体量游戏，包含四片通过木桥相连的海岛、三个恢复阶段、九页档案、昼夜潮汐、房间陈列、小海豹和自动存档。美术采用程序化几何与柔和配色；家具通过三套固定布局摆放。

本次扩建将可行走面积扩大至原来的约四倍，加入月贝沙洲、绣球花岛和观星岬。新增细节包括灯塔平顶露台与护栏、小屋窗帘与书架、角色雨帽与背包、成片花草、草地纹理、浅海光纹、岸边浪花和昼夜天空。

主角现按三张参考图重做为立体灯塔守护者：奶油黄宽檐雨帽、棕色短发、无五官的小脸、暖橙雨衣、翻领与三颗纽扣、灯塔胸针、绿色背包和贝壳挂件、深蓝雨靴与浅色鞋底。走路摆臂迈步，踏浪时张开双臂、前后错脚。四套配色仍通过 V 切换并保存。模型与动作位于 `scripts/keeper_appearance.gd`，参考图保存在 `docs/character-reference/`，实际引擎渲染见 `docs/主角-三视图.png` 和 `docs/主角-海岛实景.png`。

中文字体为 Noto Sans CJK SC，许可见 `assets/fonts/LICENSE.txt`。本地 macOS 应用包含 Apple Silicon 与 Intel 架构；本机验证平台为 Apple M2。外部分发尚未做 Apple 公证。
