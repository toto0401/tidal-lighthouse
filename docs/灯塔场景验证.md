# 灯塔内部场景 · 2026-10-10

## 游玩路线

海岛塔门 E → 灯塔一层小屋 → 右后方楼梯 E → 塔顶灯室。
塔顶舱门 E 可返回小屋，小屋出口 E 返回海岛塔门外。所有入口开局开放。

小屋、档案台和家具已移入独立室内场景。B / 1 / 2 / 3 在室内布置；三套陈列的碰撞随家具移动。灯芯修复点仅在塔顶，仍需漂流木星标、月光海玻璃和回声贝壳；修复会同时点亮塔顶灯室和室外灯塔。

## 运行验证

Godot 4.7.2，macOS / Apple M2。测试使用独立临时存档或 test_mode，不修改正常玩家存档。

- `tests/lighthouse.gd`：塔门和楼梯的 E 互动、真实 PackedScene 切换、淡入淡出期间重复输入、室外碰撞停用和恢复、小屋内跳跃与布置、修复前置条件、塔顶护栏、地图返程、门口落点、反复加载卸载、修复和家具存档、室内重新开始。Headless 与 Metal 实时渲染均通过。
- `tests/navigation.gd`：实际 WASD / E / T / N 从出生点步行，收集九件物品，经塔门与楼梯上塔顶修复，再原路返回，完成花园、海湾和结局。
- `tests/progress_integration.gd`、`tests/save_state.gd`：原有存档兼容、家具和阶段状态、读写与重开。
- `tests/smoke.gd`、`tests/menus.gd`、`tests/ui_layout.gd`、`tests/camera.gd`、`tests/jump.gd`：基础交互、菜单、640×480 / 960×540 布局、镜头与跳跃。
- `tests/activities.gd`、`tests/water_activities.gd`、`tests/wave_dash.gd`、`tests/swim_bounds.gd`：闲趣、钓鱼、游泳、陆地与水上冲刺、近海边界继续可用。

部分固定步长 Headless 测试退出时仍有已知的两首 OGG 配乐资源清理提示；断言通过，实时 Metal 灯塔测试没有这些提示。

已重新导出 `release/潮汐灯塔.app` 与 `release/潮汐灯塔-互动版.app`，包含两个新的场景资源。两份应用均通过 `codesign --verify --deep --strict`，从 `/tmp` 启动独立安装包的 120 帧 Headless 检查正常退出；结束时有同样的 OGG 清理提示。两份配套 macOS ZIP 均通过 `unzip -t`。
