# 岛上闲趣验证 · 2026-10-10

交付应用：`release/潮汐灯塔-互动版.app`，压缩包为 `release/潮汐灯塔-互动版-macOS.zip`。本机使用 Godot 4.7.2、Apple M2 / Metal 验证，应用同时包含 arm64 与 x86_64 架构。

## 新增玩法

- 主岛北岸水漂码头：E 准备与投石，指针位置决定 1 / 3 / 5 跳，动态水纹和石子轨迹反馈结果，保存最高纪录。
- 东岛口袋花圃：鼠标或 1 / 2 / 3 浇水，三盆花各经历种子、嫩芽、花苞、盛开。同步修改世界模型并恢复存档。
- 西岛贝壳风铃：三首五音旋律、数字谱、音高与亮光反馈、可视化示范。输错可重来；关闭立即取消示范的延迟回调。
- 北岬连星望远镜：仅在月夜连接两张星图，鼠标和数字键均可用；点错保持已有连线。白天提供明确的「等到月夜」按钮。
- J 手账与暂停菜单新增「岛上闲趣」，共九项记录；地图增加四个绿菱形。旧档、自动保存、完整备份和重开均兼容。

## 测试结果

以下七组通过：

| 测试 | 验证内容 |
| --- | --- |
| `tests/activities.gd` | 四种玩法全流程、真实鼠标事件和数字键、错误输入、完整示范及中途关闭、九项奖励、远距离不可打开、昼夜条件、640×480 布局、自动保存、重启恢复、备份重开 |
| `tests/activity_walk.gd` | 从出生点用 WASD 走到四处互动，无传送；实际 E 打开；菜单阻断走路、跳跃与冲刺；Esc 后没有残留输入 |
| `tests/save_state.gd` | 旧存档迁移、缺失及损坏数据、成长范围、类型验证、原子替换 |
| `tests/progress_integration.gd` | 九件遗物、三处修复、结局、小海豹、布置、存档及重开 |
| `tests/menus.gd` | 标题、暂停、档案、布置、菜单输入隔离 |
| `tests/ui_layout.gd` | 帮助返回路径与鼠标关闭，960×540、640×480 下原有菜单布局 |
| `tests/water_activities.gd` | 自由游泳、上下岸、岸边 F 钓鱼、取消与钓鱼存档兼容 |

`activities.gd` 另以真实 Metal 渲染、60 FPS 运行，全部通过且无脚本错误。检查了四种活动大窗口截图以及 640×480 紧凑布局，互动图与操作按钮均不需要滚动。小星图的两种图案全部按钮均位于画布内。

极快的无头运行偶尔在退出时报告既有 OGG 音频资源释放警告；真实帧率的活动测试及导出应用启动没有此警告。

## 导出检查

macOS release 导出成功，`codesign --verify --deep --strict` 通过。从 `/tmp` 直接启动导出应用的内置可执行文件，使用 `--headless --max-fps 60 --quit-after 120`，正常加载打包资源并以 0 退出，无错误。
