# 高处滑翔 · 2026-10-11

塔顶右侧起飞点 E → 切回海岛上空 → 展开滑翔翼。其他室外高处离地至少 2 米时 G 展翼；WASD 转向，G / 空格收翼，落地或入水自动收翼。无需解锁，旧档可直接使用。

## 行为边界

滑翔持续下降，不提供升力、体力条或空中冲刺。展开要求足够离地高度，普通平地跳跃不能起飞。滑翔翼本身为视觉模型，碰撞仍使用角色胶囊。塔顶护栏保留，从明确标记的起飞点进入空中场景。空中按 Tab 回家可随时结束滑翔；再次启动仍从灯塔外开始。
