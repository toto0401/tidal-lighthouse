# 潮汐灯塔 · 岛屿配乐

两首为本项目编写的原创合成器乐，无外部歌曲、录音或采样。

- `sea_breeze.ogg` · **海风慢步**：白昼的柔和拨弦、电钢琴与暖和弦。
- `moonlit_tide.ogg` · **月色潮汐**：月夜的疏朗琴音与缓慢氛围铺底。

两首均为 D 大调、72 BPM、32 小节（约 1 分 47 秒），44.1 kHz 立体声
Ogg Vorbis。共享和声与小节位置，同步循环，昼夜切换以 3 秒交叉淡化衔接。
混响尾音循环叠回开头，避免循环处截断。游戏内保留海浪和交互提示音，
M 键或暂停菜单中的声音开关一起控制音乐与音效，并沿用现有声音偏好存档。

源乐谱与合成脚本：`tools/render_music.py`。使用 Python 3.12，先安装
`tools/music_requirements.txt` 中的依赖，再运行 `python3 tools/render_music.py`
即可重建音频。编码完成并校验后才替换资源，避免编辑器导入未完成的音频。
游戏运行时直接播放随包音频，不运行生成脚本、不联网。
